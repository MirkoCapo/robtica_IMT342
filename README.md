# 📘 Robótica

Este repositorio contiene todo el material de la materia de **Robótica**, organizado en carpetas para clases, tareas y proyecto final.

---

## 📂 Estructura de Carpetas
├── clases
│   └── (aquí irán los apuntes y materiales de cada clase)
├── tareas
│   └── (aquí se guardarán las tareas asignadas)
└── proyecto
└── (aquí estará todo lo relacionado con el proyecto final)

---

## 📚 Clases

La carpeta `clases` contendrá los apuntes y materiales de cada sesión.

---

## 📝 Tareas

La carpeta `tareas` almacenará las tareas realizadas durante el curso.

---

## 🚀 Proyecto Final

La carpeta `proyecto` incluirá la propuesta, avances y entrega final del proyecto integrador.

---

## ✅ Objetivo del Repositorio

Este repositorio servirá como **bitácora digital** para organizar y dar seguimiento a todo el contenido de la materia de Robótica.  
Cada clase, tarea y proyecto quedará documentado de manera clara y accesible.
